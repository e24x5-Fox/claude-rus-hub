Статус актуальности мода или перевода
===================================

Для уже выпущенной версии откройте Actions → «Актуальность мода или перевода» → Run workflow.
Укажите слаг (`lucidcheats` — мод Lucid Cats, `lucidcats` — перевод), точный Steam buildid,
версию установщика и что проверено. После выполнения отметка появится в каталоге.
Номер сборки берётся из appmanifest_<appid>.acf в папке steamapps; это не версия мода.

Новые релизы получают отметку автоматически, если вместе с установщиком опубликован
`compatibility.json`. В мастерской он создаётся после проверки командой:

```
python tools/confirm_compatibility.py --game dragnwash --build 26443382 --note "Установка и откат проверены"
```

Прикрепите `games/dragnwash/dist/compatibility.json` к релизу вместе с EXE до публикации.
Workflow проверяет игру, версию тега, имя и SHA256 установщика (если GitHub возвращает digest).
Новый релиз без записи не считается новой проверкой. Последующее обновление Steam снова
покажет «проверяем», пока не появится подтверждение для новой сборки.

Локальная команда из корня каталога (после неё сохранить и опубликовать изменение):

```
python tools/compatibility.py --slug lucidcheats --build НОМЕР --version 1.0.1 --note "Запуск и функции мода проверены"
```

Добавьте `--broken`, чтобы явно отметить неисправность. Не подтверждайте работоспособность
по одному факту создания EXE. Трекер продолжает подтверждать неизменившиеся файлы и проверять журнал BepInEx.
